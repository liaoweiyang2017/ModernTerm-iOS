# Specification: 跨平台 .term 加密连接包

日期：2026-10-18。状态：用户已确认详细规范和方案，进入实现与验收。用户明确 iOS 真机部署由其明天执行，本次仅调试、构建和上传。

## 目标与用户故事

- US1：iOS、Android 的已保存 SSH 列表支持多选、全选，导出一个包含所选连接的 `.term` 文件。
- US2：两端均可选择一个或多个 `.term` 文件，解密、预览后批量导入；iOS 导出的文件可在 Android 导入，反向亦然。
- US3：默认只包含配置；用户显式打开“包含凭据”后，包含这些连接已保存的密码、私钥和私钥口令。文件无论是否含凭据都必须加密。

## 业务规则与边界

- FR-001 配置包含稳定 UUID、名称、Host、Port、User、分组、收藏、认证方式，以及可选 distribution 元数据。用户名中的 @、大小写、私钥换行、凭据内容原样保留。Android 目前无 distribution 字段，实施时需保留这个可选字段，避免往返丢失。
- FR-002 不包含终端历史、正在运行的会话、主题、宏、监控数据或已信任指纹；导入后不会自动连接，首次连接仍按现有策略确认主机指纹。
- FR-003 导出时选择连接、是否包含凭据、设置并再次输入文件密码。密码不少于 12 个 Unicode 标量，最多 1024 UTF-8 字节；不自动去除空格，规范化 NFC。提示使用独立的长密码。文件密码不保存、不记录日志，遗忘后不能恢复。
- FR-004 文件为带版本的二进制加密容器；Host/User/名称/凭据均不得出现在明文头部。内部载荷允许采用 UTF-8 JSON，但只以认证加密后的密文写入文件。扩展名或二进制本身不提供保密性，保密性来自加密和密码强度。
- FR-005 多文件可逐个输入不同密码；全部文件完成验证后展示统一预览和“新增/重复/冲突”数量，确认后写入。本次选中任一文件无效或用户取消，不导入任何条目。
- FR-006 UUID 相同：默认跳过并保留本机配置和凭据；可选择“作为新连接导入”，产生新 UUID。包内/多个包之间完全相同的 UUID 和内容合并一次；同 UUID 不同内容标为冲突，用户明确选择一个版本或跳过。UUID 不同但地址相同允许并存，不据此覆盖。
- FR-007 本次导入最多 200 条，导入后总连接数不超过 200；每个文件及所选文件总大小均不超过 16 MiB，每次最多 20 个文件，单个私钥不超过 1 MiB。拒绝未知版本、非法字段/端口、重复异常、超限长度、截断、尾随数据、认证失败。大小在读取和解析各阶段都有边界。
- FR-008 错误密码与篡改统一提示“密码错误或文件已损坏”，不暴露载荷。预览隐藏秘密。没有勾选包含凭据时不得读取凭据库；导入凭据写入现有 iOS Keychain / Android Keystore 保护的存储。
- FR-009 正常运行中的存储失败回滚本批新增记录及凭据，不修改已有条目；进程意外退出后的恢复方案在实现前验证，不能以简单多次写入宣称跨存储原子事务。
- FR-010 通过 iOS 文件选择/分享及 Android SAF 读写；临时分享文件也仅为密文，用完清理。用户选中的原文件不自动删除；不要求全盘访问权限。
- FR-011 两端沿用当前 0.2.3 版本名称；构建号如需提升，两端统一提升并在交付记录说明。现有迁移 JSON 功能保持兼容，但不得把它作为新功能默认导出格式。

## 验收标准

| ID | 标准 |
|---|---|
| A01 | 两端可多选/全选导出；无选择不可导出；取消无副作用 |
| A02 | iOS→Android、Android→iOS 各导入多个连接，字段/Unicode/@用户名/换行无损 |
| A03 | 默认无凭据、显式包含后凭据完整；没有凭据的导入保持认证方式并提示补充 |
| A04 | 同样内容/密码两次导出字节不同；文件中无样例 Host/User/秘密明文；文件密码不持久化 |
| A05 | 正确密码成功；错误密码、头部/密文篡改、截断、尾随数据、未知版本、超限全部失败且不新增连接 |
| A06 | 多文件同/不同密码、重复、冲突、新 UUID 副本、容量不足均符合规则；本机记录和凭据不被覆盖 |
| A07 | 注入凭据/配置写入失败验证回滚；进程中止恢复按最终技术方案测试并披露限制 |
| A08 | 导入不自动连接、不转移信任；首次连接依旧要求指纹确认 |
| A09 | iOS 模拟器、Android API29/36 验证文件流程、密码输入、明暗与批量选择；Huawei 真机仍标记未验证 |
| A10 | 共享固定测试向量、双向跨语言解码、单元/仪器测试进入 CI；更新规范、验收记录和安装包 |
