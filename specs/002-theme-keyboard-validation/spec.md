# Specification: 自动主题和系统键盘核验

日期：2026-10-17。状态：已获用户执行授权，验证及同版本交付。

## 需求与边界

用户最初报告 Ubuntu Neo 自适应配色未随浅色模式变化，要求保持版本号、重新部署到手机，并将本轮修复与规范、验收文档提交推送。随后确认主题正确，转而询问手机系统键盘无法弹出。

- 自动配色跟随应用有效外观；固定深色和浅色配色保留其明确选择。
- 正常进入终端时请求系统文字键盘；隐藏、重新显示和退出页面维持现有行为。
- 必须区分应用焦点和电脑远程控制造成的虚拟硬件键盘状态，不能用修改应用掩盖环境原因。
- 版本保持 0.2.3 / build 5。保留原会话、配色选择和 Keychain，完成重部署及 GitHub 提交推送。

## 验收

| ID | 通过标准 |
|---|---|
| TH-01 | Auto 在实际 UIViewRepresentable 中暗→浅→暗切换，重新挂载到浅色窗口后背景与前景正确 |
| KB-01 | 正常终端输入视图为系统键盘（inputView 为 nil），已附加窗口后取得焦点，已有隐藏/重开测试通过 |
| KB-02 | 退出电脑预览后，用户在手机点击右上角按钮可弹出系统文字键盘 |
| DL-01 | 同版本构建通过，重新部署后实际 Info.plist 仍为 0.2.3 (5)，原数据容器保持一致 |
| DL-02 | SSH 修复、测试、规范及验收记录一起提交并推送 origin/codex/ios，远端提交哈希核对一致 |

不包括改变系统键盘布局、强制覆盖外接键盘行为、重写终端控件或把固定深色主题改成自动。
