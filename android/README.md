# ModernTerm for Android

Kotlin + Jetpack Compose / Material 3. Version **0.2.3 (5)**, `minSdk 29` (Android 10), `compileSdk/targetSdk 36`. The release package is `com.modernterm.android`; debug builds use `.debug` and have separate data.

## Features

- Server editing, search, groups, favorites and up to eight live sessions.
- Password and OpenSSH RSA/Ed25519 private keys (including passphrases), RSA-SHA2 host signatures, SHA-256 fingerprint confirmation and changed-key rejection.
- Local bundled terminal with Chinese IME, PTY resize, keyboard controls, copy/paste through WebView, 18 palettes and Ubuntu Neo Auto.
- SFTP listing, Storage Access Framework uploads/downloads, sharing, protected directory deletion, UTF-8 editing up to 2 MiB and baseline conflict checks.
- Read-only Linux CPU/core, memory/swap, network/TCP, disks/IOPS, temperature, available NVIDIA/Docker/process metrics, 60-sample trends and multi-server overview.
- Saved commands, optional host-matched OSC 7 directory following and v1 Mac migration JSON import.
- System/light/dark appearance, Android 12+ dynamic colors with Android 10 fallback, large-screen navigation rail and server/detail layout.
- Android Keystore-encrypted credentials, no Google Play Services requirement, no telemetry or credential sync. Connections end when the app goes into the background; temporary file-picker flows have a bounded grace period.

Native HarmonyOS/HAP is not included. Mate 70 compatibility depends on its exact system and APK runtime; no Huawei physical-device validation has been performed. A system Android WebView is required. Terminal JS is built for Chrome 70 syntax and tested on the available WebView versions, rather than loaded from a CDN.

## Build

Install JDK 17 and Android SDK 36/build-tools 35.0.0. Set `ANDROID_HOME` or create ignored `local.properties` with `sdk.dir=...`.

```sh
cd android
./gradlew lintDebug testDebugUnitTest assembleDebug
```

Run `python3 scripts/sync_shared.py --check` to check the palettes and monitor script against their iOS-owned sources. Rebuild terminal assets with `pnpm --dir terminal install --frozen-lockfile` then `pnpm --dir terminal run build`; pinned dependencies and licenses are included.

For local builds in a synchronized Documents folder, set `MODERNTERM_BUILD_ROOT` to an ordinary cache directory outside that folder and optionally pass `--project-cache-dir`. CI uses the standard `android/app/build/` paths.

## Integration tests

Use a disposable Android API 29/36 emulator. Install `paramiko==4.0.0` into a Python venv, start `python android/scripts/ssh_fixture.py` from the repository root, then run `./gradlew connectedDebugAndroidTest` inside android/. The server listens only on the runner's loopback interface; emulator `10.0.2.2` reaches it. It creates fresh keys/passwords and a temporary SFTP directory, never reads a user's SSH files, and removes its private test configuration when stopped normally or with SIGTERM.

The fixture ports are 22222 (normal), 22223 (restricted subsystem), 22224 (legacy-only host signature, which must be rejected). Its generated test-only JSON is ignored and is never packaged in the production APK. Do not commit it or distribute the test APK.

Tests exercise Android ART crypto providers, native IME composition, actual terminal viewport and output replay, SFTP rejection, credentials/migration, shared metric expectations, Material navigation, activity recreation and landscape. Screenshots generated by instrumented tests contain clearly marked fixture data and are saved to the emulator's Pictures/ModernTerm-tests directory.

## Signing and installation

A release APK must use the fixed signing identity. Locally it is kept outside Git under `~/.codex/private/modernterm-android/` (`release-signing.jks` and protected `credentials.json`). Back up these files securely to preserve future update capability; do not check them into Git or include them in an APK.

`JAVA_HOME=... python3 android/scripts/build_release.py` builds with that identity. Alternatively provide `MT_STORE_FILE`, `MT_STORE_PASSWORD`, and `MT_KEY_ALIAS` to Gradle. CI uses encrypted repository secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, and `ANDROID_KEY_ALIAS`; no signing secrets are provided to PR jobs. A first install may require enabling installation from the selected download source on the phone. No root is required.

The installable release APK and SHA-256 file are delivered in the private repository's Android release and as local build artifacts. GitHub access is required to download private release attachments. Debug and release packages do not overwrite one another.

## CI and limits

`.github/workflows/android-ci.yml` compiles, lints, runs JVM tests and API 29/36 emulator integration tests. Successful non-PR runs also build a signed release. It uses minimal token permissions and actions pinned to commit hashes.

At implementation time the account's Actions artifact storage quota was exhausted. Artifact-upload steps therefore report a warning without hiding build/test failures. Test outcomes remain in run logs/step summaries. Installable APK delivery uses a repository Release attachment/local file; this does not require deleting artifacts from unrelated projects. Normal artifact uploads resume when the account has available storage.

Simulation does not prove Huawei ROM, actual ARM phones, third-party keyboards or HarmonyOS compatibility. See `../specs/003-android-material/validation.md` for actual evidence and remaining verification limits.

## Scope limits

No local shell, SSH tunnel, permanent background daemon, automatic reconnection, recursive transfer, privileged server configuration or automatic command replay. Remote editing uses baseline comparison plus temporary-file replacement and is not a multi-user transaction. GPU/Docker data requires existing server commands/permissions. Migration input files are not deleted automatically. Release shrinks neither reflective crypto classes nor terminal assets; it prioritizes verified compatibility over minimum APK size.
